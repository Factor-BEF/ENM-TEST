## Historical species & human-impact test data

A reproducible ENM data package is available at:

`data/historical_species_human_impact/`

It contains:
- Plant: *Picea mariana* (black spruce), Canada annual dominant-species maps, 1984–2022.
- Animal: *Vulpes vulpes* (red fox), fixed GBIF historical occurrence archive, 1980–2017.
- Human activity: Global Human Modification v3 historical overall modification, 1990–2020.

See the package README and `data_catalog.csv` for source IDs, DOI/licence information, and reproducible GEE/GBIF acquisition scripts.
